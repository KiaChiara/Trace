# 흔적 (Trace)

An interactive audiovisual piece by Chiara Giustiniani.
The visitor's face plays the piece: expressions shape the music and bend the
lines, every gesture leaves a mark, and at the end of the visit the marks
become a 흔적, a trace.

The camera image is processed in the browser and is never uploaded.

Built with p5.js, Tone.js and MediaPipe Face Landmarker.
